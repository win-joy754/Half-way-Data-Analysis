# Half-way-Data-Analysis
An ongoing Data analysis project 
# ABOUT THE PROJECT
half-way data analysis project is focused on exploring data, identifying meaningful patterns and generating insights through data analysis and visualization.
The project uses MySQL, python, power BI and weka to explore ,analyze ,visualize and model data.
# objectives
Explore and understand the dataset
clean and prepare the data for analysis
use SQL to query and analyze data
perform data analysis using python
create an interactive dashboard using power BI
apply machine learning techniques using Weka
present meaningful insights from the data
